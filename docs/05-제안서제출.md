PDF 다시 뽑기:

```bash
python proposal/build.py
powershell -NoProfile -ExecutionPolicy Bypass -File proposal/print.ps1
```

원고는 `proposal/body.html`(본문), `style.css`(디자인), `figs/*.svg`(그림)로 나뉘어 있고 `build.py`가 `proposal.html`로 합친다. `proposal.html`은 직접 고치지 않는다.
현재본은 3파트 22쪽: PART 1 패킷 흐름 → PART 2 구축 계획 → PART 3 운영 설계. 같은 구성의 쉬운 버전은 `body-easy.html` → `elice-infra-proposal-easy.pdf` (`python proposal/build.py easy`, `print.ps1 -Src proposal-easy.html -Out ..\elice-infra-proposal-easy.pdf`).

디자인은 포트폴리오(`Desktop\code\이력서\portfolio3.html`)와 같은 체계다. Pretendard는 jsDelivr CDN에서 받으므로 인터넷이 필요하다.

### 막히는 지점 예상

- Git Bash에서 msedge.exe를 직접 부르면 경로의 백슬래시가 꼬여 조용히 아무것도 안 만든다. print.ps1을 쓴다
- print.ps1에 한글 주석을 넣으면 PowerShell 5.1이 BOM 없는 UTF-8을 잘못 읽어 파서 오류가 난다
